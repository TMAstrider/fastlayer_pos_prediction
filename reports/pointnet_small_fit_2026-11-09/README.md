# 小样本固定朝向拟合诊断（2026-11-09）

从主实验 932 个训练零件中固定随机选择 8 件，不使用原 100 件验证零件训练。每件固定 16 个训练旋转、64 个另外的旋转，2048 点、batch32。PointNet 从头训练，全网更新，关闭 dropout 和 weight decay，恒定 lr=0.001，余弦损失与主实验一致。
