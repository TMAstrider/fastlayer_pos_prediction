# 打分器实验 3：去中心 + 随机 yaw（2026-11-10）

状态：可用基线（当前唯一可信的打分器版本）。**结论：泄漏清除后，排序能力仍明显优于物理规则，
但分数场太平，argmax 选不准（top-1 48°）。**

## 目的

在实验 2 基础上修掉“绝对位置”泄漏：编码器输入先**去中心 + 按最大半径归一**，再按候选方向旋转；
物理项仍用原始坐标（2 mm 接触带需要真实尺度）。其余配置不变。

## 配置

| 项 | 值 |
|---|---|
| 输入 | 2048 点，中心化 + 尺度归一 + 按候选旋转 + 随机 yaw |
| 正样本 | 人工方向 |
| 负样本 | 3 硬负（代价前 10%，离人工 >20°）+ 2 随机（早期版本 4+4，见 config） |
| 损失 | listwise softmax，温度 0.05 |
| 模型 | 116,289 参数 |
| 优化 | AdamW 1e-3，40 轮，batch 48 形状 |
| 评估 | 512 候选 + 8×4° → 4×2° → 2° 八方位爬山细化，yaw 平均 4 |

## 结果（100 留出件，第 5 轮权重）

| 指标 | 模型 | 物理规则 | 单方向回归（旧） |
|---|---:|---:|---:|
| 细化 top-1 中位 | **48.2°** | 86.8° | 63.95° |
| 细化 top-1 均值 | 73.1° | 77.9° | — |
| ≤10° / ≤20° / ≤30° | 23% / 28% / 35% | — | — |
| top-5 最近候选中位 | 16.5° | — | — |
| top-5 含 ≤20° 候选 | **52%** | 15–19%（K=8） | — |
| 人工方向分位（中位） | **0.0137** | 0.0508 | — |
| 人工进入前 10% | 78% | 68% | — |
| yaw 敏感度（分数极差中位） | 0.028 | 0 | — |
| 距人工 3°/5°/10° 分数下降 | 0.006 / 0.013 / 0.051 | — | — |

按“物理规则是否已经把人工排进前 10%”分组：

| 子集 | 件数 | 模型人工排名中位 | 规则人工排名中位 | 模型 top-1 中位 |
|---|---:|---:|---:|---:|
| 规则已经很好 | 68 | 0.006 | ≤0.10 | 48.2° |
| **规则失败** | 32 | **0.088** | **0.193** | 54.3° |

## 诊断

1. **泄漏已消失**：3° 只掉 0.006 分（实验 2 是 0.164），yaw 敏感度 0.028，分数场平滑。
2. **排序确实变好**：人工方向中位排到 512 候选的第 7 位（前 1.4%），规则是第 26 位（前 5.1%）；
   在规则失败的 32 件上从 19.3% 提到 8.8%。
3. **但 top-1 没解决**：细化后仍有 48°，因为分数在人工附近几乎是平的（3° 掉 0.006），
   模型没有理由把 argmax 放在人工附近；它只保证“人工比大多数候选高”，不保证“人工是最高”。
4. **训练 loss 只从 1.39 降到 1.02**（随机为 ln 9 ≈ 2.20），说明**欠拟合**，不是过拟合：
   116k 参数、932 形状、40 轮，还没把训练集拟合到接近 0。

## 结论

- 这是目前唯一可信的打分器基线：**排序有效，生成无效**。
- 由此得到两个可选方向：(a) 加近距离负样本，让场在人工附近有梯度（实验 4）；
  (b) 承认打分器只做“验证/排序”，候选生成交给物理规则或人工（top-k 形态）。
- 实验 4 验证 (a)。
