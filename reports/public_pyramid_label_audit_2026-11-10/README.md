# 公开金字塔数据集：标签到底是什么（2026-11-10）

状态：完成。**结论：每个样本只有 1 个标签，是生成器给的“参考朝向”，不是唯一的可接受姿态；
而且它不是任何“面着地”的稳定姿态——金字塔是指尖朝下站着（接触面积 ≈ 0）。**

## 数据包里有什么

`datasets/public_pbflbm/pyramids_10000.zip`（14.8 MB，PBFLBM 数据集 A）：

- 10,000 个参数化多棱锥：`info/pyramids_XXXXXXX.json` + `stl/{train,validation,test}/pyramids_XXXXXXX.stl`
- 官方划分：训练 8,100 / 验证 900 / 测试 1,000
- JSON 字段：`height`、`radius`、`n_longitude`（底面边数）、`n_latitude`（细分）、`n_plane`、
  `initial_psi`、`phi`、`theta`、`psi`、`num_triangles`、`num_vertices`、
  `target_rotational_matrix`、`target_rotational_matrix_transpose`、`target_rotation_6d`
- 三个旋转字段是**同一个旋转的三种编码**（矩阵、转置、6D），不是三个不同标签；
  没有可接受姿态集合、没有分数、没有工艺参数

抽样 24 件的参数范围：底面边数 4–10，底面半径 10–47 mm，高度 20–97 mm。

## 标签的几何含义

恢复 `V_reference = V_input @ M` 后（M = `target_rotational_matrix`）：

| 检查 | 结果 |
|---|---|
| 平坦多边形底面在恢复坐标系的位置 | **顶部**（24/24） |
| 尖顶位置 | **底部**（24/24） |
| 标签朝向下的悬垂面积（排除贴床面） | 0.0 |
| 标签朝向下的首层接触面积 | **0.0**（只有一个顶点接触） |
| 标签姿态是否稳定 | **0/24** |

即：数据集把金字塔摆成**尖端朝下、底面朝上**，这在几何上“没有悬垂”，因为它是一个从尖端
逐层长大的形状；但它只有一个点接触，静力学上站不住，也不适合真实打印（导热、粘附、首层）。
这不是“打印最优朝向”，而是**生成器/设计坐标系的规范朝向**。

## 可接受姿态有几组？

对每个面枚举“以该面着地”的姿态，判据：悬垂面积 ≤1%（排除贴床面）、接触面积 >0.1%、
质心投影落在接触多边形内。

| 指标 | 结果（24 件） |
|---|---|
| 每件可接受姿态数 | 中位 **3**，均值 3.5，范围 0–9 |
| 数据集标签本身就是可接受姿态 | **0%** |
| 标签与最近可接受姿态的夹角 ≤10° / ≤20° | **0% / 0%** |
| 无任何可接受姿态的样本 | 存在（高瘦金字塔侧躺会翻倒） |

可接受姿态基本是“某个侧面着地”（同一形状按底面边数对称，常有 4–9 个等价姿态）以及“底面着地”；
数据集的标签不在其中，也不在 20° 附近。

## 这对我们意味着什么

1. **你的直觉是对的**：这些简单件的“正确答案”本来就是一个集合，而不是一个方向；
   数据集只记录了其中一个规范朝向，且这个朝向连稳定姿态都不是。
2. **金字塔上的 0.463° 只证明“形式能拟合一个定义明确的单值目标”**，不证明模型学会了可打印性；
   把它当成“简单件能摆对”的证据要打折扣。
3. 但这也提供了一个干净的**集合式目标**来源：几何本身就是精确的，可以自己枚举可接受姿态，
   不看数据集给的那个标签。于是“简单件先摆对”可以定义成：
   **输出落在可接受集合内**（集合距离 ≤ 容差），而不是“角度接近某个人工方向”。
4. 现有物理代价里的悬垂项把“贴着床的朝下面”也算成悬垂（金字塔底面朝下时会得到 20% 悬垂），
   这是缺陷；本审计已用“排除贴床 2 mm 内的面”修正，后续报告需统一口径。

## 建议的下一步（改动小、判定明确）

用金字塔数据做**集合式监督**的对照实验：

- 目标：对每个样本预计算可接受姿态集合（面着地 + 稳定性 + 悬垂判据，已验证可算）；
- 训练：正样本 = 集合内任意方向，负样本 = 集合外方向（含“接近但不可接受”的）；
- 指标：top-1 / top-k 落在集合内的比例、集合距离中位；
- 意义：如果这能做到 90%+，就说明“简单件摆对”在**多解**定义下也成立；
  如果做不到，问题就出在“多解本身的排序”，而不是单值标签。

## 局限

- 悬垂按面积与 40° 规则计算，不是切片支撑体积；稳定性只做静力学质心检查，不含热变形与残余应力。
- 面法向分组基于 STL 三角形，未处理共面三角形拼接与网格缺陷。
- 只抽了 24 件做标签审计，不是全量 10,000 件的统计。
