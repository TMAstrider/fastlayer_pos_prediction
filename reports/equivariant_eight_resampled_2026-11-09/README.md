# 八件旋转等变网络实验（2026-11-09）

Vector Neuron 思想的独立轻量实现，不宣称原论文完整复现。所有可学习向量通道混合无坐标偏置，非线性使用向量投影，注意力与 head 权重只依赖旋转不变量；XYZ×法向叉积适用于 SO(3)。输入 XYZ+法向，固定原八件相同 2048 点；不使用 GT 方向输入、PCA 帧、零件 ID 或支撑。

原八件索引 [69, 147, 232, 546, 644, 659, 790, 843]，在线 SO(3)，batch32，每件每轮 16 朝向、每轮 4 更新，AdamW lr=0.001 余弦到 1e-5，无 dropout/weight decay，有向余弦损失，梯度裁剪 1。在线重新抽点：True；若启用，从原始 4096 点每次无放回取 2048 点，法向按相同索引取；独立采样 RNG，不改变训练 SO(3) 生成序列。probe/test 保持原固定点。模型从头训练，参数 10576。原法向 PointNet 是已有 XYZ 权重续训，初始化和网络容量不同，不能当严格单变量消融。

完成 700 轮、2800 次更新，用时 0.94 分钟，按同件 probe 选第 600 轮。没有在新零件上选模。最终独立 512 旋转与旧法向实验逐元素标签一致，平均误差 **1.606°**，中位 **1.510°**，≤3° 87.50%，≤10° 100.00%，loss **0.000530**。

初始和最终旋转等变、点序不变、batch 独立检查均已通过，最大旋转向量残差见审计 JSON。架构等变不保证方向正确，也不能从完美对称的几何唯一推出有向标签；当前每件固定有限点与三角面法向可能带有采样微小不对称，低误差不意味着识别了工艺语义。所有件计入总体，没有对 69 号改标签或取 abs(dot)。本轮只测同件的新旋转，不声称新形状泛化。
