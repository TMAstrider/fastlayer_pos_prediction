# 历史姿态偏好融合实验

## 设置

- 历史姿态：输入网格保存坐标系的 `+Z`
- 合成 GT：256 个采样方向中支撑投影面积最小者
- 历史 head：在冻结的点云/方向交互编码器上训练
- 融合：对每件零件的面积分数和历史偏好分数分别做 z-score，
  再计算 `area_z + alpha * history_z`
- development 零件：10
- test 零件：100
