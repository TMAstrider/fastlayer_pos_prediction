# 按形状去重的数据版本（2026-11-09）

本版从初始 193 个 PJF 主零件、额外 30 个 PJF 主零件，以及新增 Magics 导出候选中，筛出 **1,032 个代表零件**用于新的训练。每组只使用一个存储打印姿态作为参考，不混用同形零件的多个 GT。原始文件和其他摆法均保留。

| 阶段 | 数量 | 含义 |
| --- | ---: | --- |
| 来源零件记录 | 5,757 | Magics 5,534 + PJF 223；不含已识别支撑、平台、Box |

| 经过刚体网格匹配归并的组 | 1,700 | 955 条配对证据，额外归并 167 份存储网格；证据条数不是重复零件数 |
| 暂不使用的待核对组 | 668 | 存在面积/表面二阶矩高度相近、但尚未确认完全同形的配对；不是已确认重复 |
| 本版使用的代表零件 | **1,032** | 当前筛选规则下没有剩余近似描述符候选对；1,019 个来自 Magics，13 个来自 PJF |

原始 PJF 223 条记录全部参加了检查；由于与其他网格存在待核对的形状相似性，只有 13 个 PJF 代表进入本版训练。其余记录的排除理由、组归属和来源仍在映射中，后续确认后可恢复。

## 规则

1. 平移、旋转及顶点/三角面索引重排不应产生新的零件。只有经过刚体配准，并核对顶点与三角面连接关系的网格才归并；最大顶点误差阈值 0.002 mm。
2. 用面积及按三角形面积精确积分的表面协方差特征，筛查潜在同形件。该特征不依赖某个面上顶点的采样密度，也允许检测部分重新划网格的候选。特征仅用于找候选，**不单独作为归并依据**。
3. 表面协方差主尺度各轴差不超过 0.02 mm、面积相对差不超过 0.1% 的未确认候选，两边所在组都暂不用于本版训练，避免一边训练一边验证。很相似但实际不同的零件也可能因此暂时排除。
4. 已确认同形的一组，只保留一份参考。选择顺序为：优先非待核对对象、优先通常接近平台的坐标、优先有命名和根零件关系的 PJF 对象，再按确定的来源顺序选择。没有依据网络结果或验证误差挑选 GT。
5. 不做尺度归一化后再判重。不同实际尺寸仍作为不同零件；零件族划分尚未完成。
6. 选中网格和点云保留原始参考打印朝向，去重过程中不将它们转到 PCA 坐标系。原始 GT 为存储坐标中的 +Z；训练施加 SO(3) 后，标签同步旋转。

## 验证

- 1,032 个不同 shape_group_id，每组一个代表。
- 所有点云均为有限的 4096×3 XYZ，每个参考 STL 路径均存在。
- 在本版保留的代表之间重新计算候选关系，剩余候选对为 **0**。
- 前次发现的 14 对至少 2° 方向差配对，均已归入各自同形组；不会作为独立样本混用不同 GT。
- 表面积分描述符通过刚体旋转、平移、共面重新三角化及物理尺度变化的人工数值检查。
- 训练脚本检查 shape_group_id 唯一，以及训练、验证的形状组交集为空。

完整核对结果见 [validation.json](validation.json)，组映射和配对证据见 [deduplication.json](deduplication.json)，选中代表见 [representatives.csv](representatives.csv)。训练实际配置和划分快照见 [训练记录目录](../pointnet_shape_dedup_2026-11-09_val100/)。

这是保守的有限容差几何筛选，**不是穷尽的 CAD 零件身份认证**。不同网格化造成的几何误差若超出候选阈值，仍可能漏检；此版本也没有完成零件族隔离、连续几何对称性审计，以及所有 Magics 对象活动状态/语义的核实。没有把待核对组都称为重复件，也没有把角度指标解释为打印可用率。

## 数据与训练

数据目录：`outputs/shape_deduplicated_pointclouds/`。其中 `manifest.json` 为训练输入索引，`inventory.json` 保留来源记录，`deduplication.json` 保留组归属与待核对原因，`surface_descriptors.json` 为可复用的候选特征缓存。

新的 PointNet 从头训练使用 XYZ 2048 点、batch32、每个零件每轮 16 个新 SO(3) 朝向、AdamW lr=0.001、余弦方向损失。验证为 100 件 × 32 个固定朝向 = 3,200 个视图。每轮把不同零件、不同随机朝向打乱后组成 batch。旧的未按形状去重的 Magics 训练，以及最初 826/206 划分的去重训练均已停止，旧权重保留；当前 932/100 划分从头训练，不续用旧权重。

新运行目录：`runs/pointnet_shape_dedup_2026-11-09_val100/`。逐轮状态在 `progress.json`；完成后写入 `metrics.json`。完成结果、配置、划分和曲线会自动归档到 `reports/pointnet_shape_dedup_2026-11-09_val100/`。新旧验证集不同，不能直接把均值变化当成去重的因果效果。

```powershell

python tools/prepare_shape_deduplicated_data.py --workers 4
```
