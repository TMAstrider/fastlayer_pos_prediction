# 人工打印摆放的物理特征与打分先验（2026-11-10）

范围：932／100 去重划分上的 1032 个形状，不训练、不修改数据与权重。
目的：先回答“师傅摆好的零件有什么特点”，再判断单方向回归是否本就用错了目标形式。

## 0. 方法

每个形状的几何保存在历史打印姿态里，因此人工朝上方向就是存储坐标系 +Z。在球面取 512 个候选方向，
用 4096 点面积加权池计算 4 个可计算量，标准化后加权成代价；人工方向在该代价下的**分位数**就是
“规则能解释多少人工选择”。代价越低越好，分位 0 表示人工就是最优，0.5 表示比一半候选差。

| 术语 | 定义 |
|---|---|
| overhang | 法向落在下轴 40° 内的面积占比（40° 规则来自现场经验） |
| support | 悬垂面积按离最低点的高度加权（支撑体积的粗略代理） |
| height | 沿该方向的零件高度 / 包围盒对角线（构建时间代理） |
| contact | 距最低点 2 mm 内、且朝下的首层接触面积占比 |

权重在 932 训练件上从 9 组候选里选，验证在 100 留出件上报告。产物：`report.json`（含模型对比）、
`placement_characteristics.json`（含摆放特征与权重组合对比）。

## 1. 单条规则能解释多少人工选择（人工方向的分位，越低越好）

| 代价 | 全量中位 | 验证中位 | 进入前 10% 的比例（全量／验证） |
|---|---:|---:|---:|
| support only | 0.060 | 0.051 | 62.8% / 63.0% |
| overhang only | 0.106 | 0.099 | 48.5% / 50.0% |
| overhang + support | 0.082 | 0.069 | 54.2% / 57.0% |
| overhang + support + contact | **0.047** | **0.051** | **70.3% / 68.0%** |
| overhang + support + height | 0.109 | 0.122 | 47.8% / 47.0% |
| contact only | 0.184 | 0.181 | 29.9% / 25.0% |

权重拟合结果：`overhang 1, support 1, height 0, contact 1`，即**高度权重被数据归零**。

40° 阈值的选择：30° → 前 10% 47%，35° → 55%，**40° → 68%**，45° → 48%（验证集）。
数据支持现场给的 40°，不是教科书常用的 45°。

## 2. 摆放形态本身

| 指标 | 结果 |
|---|---|
| 有大平面与平台平行（≤5°） | **19.7%** |
| 最近大平面相对平台的倾斜角 | 中位 **45.0°**，25 分位 22.5° |
| 首层接触面积占比 | 中位 **0.1%**（代价 argmin 为 4.5%；argmin 有 46% 的零件 >5% 接触，人工只有 8.1%） |
| 保留悬垂面积 >5% 的零件 | 26.8%（>10%：8.4%） |
| 悬垂比最优方向多 5% 以上的零件 | 18.4% |
| 高度 | 中位 94.4 mm，为包围盒对角线的 0.66 |
| 大平面数量（≥1% 面积） | 中位 16 个 |

解读：

1. **人工基本不“平躺”零件**：只有约五分之一有大平面贴平台，接触面积中位 0.1%，零件多数以
   小特征或支撑站住，往往被“立起来”（高度方向接近包围盒最长方向）。因此“最大化平台接触”
   不是师傅的目标；把它写进代价会直接把最优解拉到平躺方向，离人工中位 87°。
2. **支撑优先于高度**：高度权重被拟合为 0，人工方向在“高度最小”这一项上中位分位 0.62（比一半候选更差）。
   这与“少支撑 > 矮”的现场经验一致。
3. **悬垂不是 0**：27% 的零件保留 >5% 悬垂（也就是用了支撑），说明目标不是“消除支撑”，而是
   “支撑少、可清除、不放在难处理的位置”。

## 3. 与已训练模型在同一指标下对比

| 对象 | 与人工方向夹角（验证） | 在该代价下的分位（验证中位） | 前 10% 比例 |
|---|---:|---:|---:|
| 等变回归 best（第 1 轮） | 63.95° | 0.35 | 29% |
| 纯代价 argmin | 77.91° | 0（最优但位置任意） | 100% |

模型比纯 argmin 更接近人工（59% 的验证件上角度更小），但它的方向在代价下只排到 35 分位，
而人工是 5 分位。**回归模型学到的方向，用现场规则衡量也只是中等；规则的 argmin 又选不出人工答案。**

## 4. 候选集覆盖率（验证集，物理代价前 K 个方向）

| K | 存在 ≤20° 候选 | 存在 ≤45° 候选 |
|---:|---:|---:|
| 8 | 19% | 65% |
| 16 | 39% | 84% |
| 32 | 62% | 98% |
| 64 | 84% | 99% |
| 128 | 96% | 99% |

只按粗糙代价排序生成候选，小 K 覆盖率不足；要把候选生成和打分分开（几何候选 + 连续搜索），
而不是指望“代价 top-K 就够”。

更关键的一点：在低代价集合里**随机挑一个**，期望角误差是 80.0°／81.4°／83.0°／83.9°／85.6°
（K=16／32／51／64／128），与球面随机的 90° 只差几度。也就是说，**规则能把人工筛进集合，却不能在
集合里选出人工**：低代价区域在球面上很宽，规则在这些方向之间几乎是平的。这正是“打分/排序”要解决的
部分，也是师傅经验真正起作用的残差。

## 5. 结论

1. 人工选择**高度符合“少支撑”规则**：单用支撑项，人工方向中位就在 6% 分位；加上悬垂与接触到 4.7% 分位。
2. 但规则**不唯一**：代价最优点离人工中位 87°，低代价区域很宽，argmin 由微小起伏决定，不稳定。
   因此“优化一个标量代价”和“回归一个向量”都不对，正确形式是**打分 + 排序 + top-k**。
3. 人工**不追求平躺、不追求矮**；把 platform contact 或 height 当目标会与人工相反。
4. 30% 的零件人工选择落在代价前 10% 之外，这部分就是规则没覆盖的**残余偏好**（窄孔/狭缝可清除性、
   配合面、功能面、装夹与后处理），也正是要蒸馏的“师傅经验”。
5. 用同一代价衡量，现回归模型的输出只到 35 分位，人工是 5 分位；模型不是“差一点”，而是目标形式不对。

## 6. 对建模的影响

- 目标改为**分数场** \(s(\text{shape}, u)\)：候选方向打分、排序取 top-k，而不是单向量回归。
- 物理项作为**先验特征或加性项**：支撑、悬垂、可清除性（文献把“无法被刀具/磨具触及的支撑”
  形式化为 secluded support volume，见 arXiv:2107.07686），不把 contact、height 当主目标。
- 训练信号：人工方向为正样本；**硬负样本来自“低代价但人工没选”的方向**，这是区分“会算”和“会选”
  的关键，而且可以自动生成，不需要额外标注。
- 评价：top-k 召回（≤5°/≤10°/≤20°）、中位角误差、物理 regret、人工一致率并列，不再只看 top-1 角误差。

## 7. 局限

- 悬垂是面积占比，不是切片的真实支撑体积；没有体积/时间量纲。
- 接触面判据用最低 2 mm 带，而这些零件的网格最低点约在平台上方 4 mm（靠支撑），接触只是弱判据。
- 大平面用 4096 个采样法向聚类检测，不是网格面分组；0.3% 的形状没有 ≥1% 面积的法向簇。
- 窄孔/狭缝可达性尚未计算；这是“不要在孔里放支撑”这条经验目前缺失的部分。
- 人工姿态可能含 Magics 自动定向的结果，本报告只衡量一致性，不判断最优性。

## 8. 复现

```bash
python tools/score_build_direction_prior.py --directions 512 --overhang 40 \
  --checkpoint runs/equivariant_full_resampled_2026-11-09/best_model.pt
python tools/characterise_human_placements.py

# 40 deg 阈值的敏感性（写入 report_theta_sweep.json）
python tools/score_build_direction_prior.py --directions 512 --overhang 30,35,40,45 \
  --output reports/build_direction_physics_prior_2026-11-10/report_theta_sweep.json
```

`score_build_direction_prior.py` 的 `candidate_coverage` 需要 `--directions`，模型对比需要
`--checkpoint`；`characterise_human_placements.py` 读取前者写出的权重，输出摆放特征与权重组合对比。
