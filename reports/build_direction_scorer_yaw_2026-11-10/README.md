# 打分器实验 2：加随机 yaw（2026-11-10）

状态：已废弃。**结论：yaw 泄漏修好了，但“绝对位置”泄漏还在，分数仍是尖峰。**

## 目的

实验 1 发现模型能识别“原始 yaw”，于是给**所有**样本（正负）加随机 yaw，推理时对 yaw 取平均。
其余配置不变。

## 配置

在实验 1 基础上：

| 项 | 值 |
|---|---|
| 训练增强 | 每个样本在规范化后再施加随机 yaw（绕 +z） |
| 推理 | yaw 平均 2 次（训练期）/ 4 次（评估期） |
| 轮数 | 40 |

评估（第 35 轮，512 候选 + 局部细化）：

| 指标 | 值 |
|---|---|
| 细化后 top-1 中位 | 44.5° |
| 细化后 ≤10°/20°/30° | 29% / 33% / 41% |
| top-5 最近候选中位 | 10.1° |
| top-5 含 ≤20° 候选 | 70% |
| 人工方向的分位（中位） | **0.002** |
| 人工方向 yaw 敏感度（分数极差，中位） | 0.030 |
| 距人工 3°/5°/10° 处的分数下降 | 0.164 / 0.354 / 0.664 |

## 诊断：位置泄漏导致的尖峰

- 人工方向在 512 个候选里排前 0.2%，**但 top-1 却在 44° 外**；两者矛盾。
- 分数曲线说明问题：偏离人工 3° 就掉 0.164，5° 掉 0.354 —— 比 yaw 噪声（0.030）大一个量级，
  所以不是噪声，而是**一个宽度只有几度的尖峰**。
- 尖峰的来源仍是坐标系：旋转没有去中心，正样本永远在“零件底在 z≈4 mm”的位置，
  负样本旋转后落在空间别处。模型学到的是“点云是否在原始位置”，窄峰就是对“精确原位置”的响应；
  网格最优点（≥5° 外）自然拿不到高分，于是 argmax 落到远处的次要极值。

## 结论

- 不能把“人工排名 0.2%”解读成模型学会了偏好；它是坐标系检测器。
- 修法：编码器输入先**去中心 + 尺度归一**，再旋转。物理项仍用原始坐标（2 mm 接触带需要真实尺度）。
- 该版本的权重和数字不进入结论。
