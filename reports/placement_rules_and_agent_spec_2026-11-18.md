# 工业零件打印摆放与支撑要求：规则整理及 Agent／模型任务定义

整理日期：2026-11-18
依据：2026-11-18 用户提供的会议纪要及两张会议材料截图，并结合本项目截至 2026-11-10 保存的模型与候选打分实验。
用途：把工艺经验转换为可确认的输入字段、硬约束、评价目标和学习信号。本文记录的是会议材料中的经验摘要，不替代工艺规范、切片验证或客户图纸。

## 1. 核心判断

摆放决策不是“给定零件几何，网络总能输出唯一正确姿态”。它实际是一个带条件的多目标问题：

> 同一个几何零件，在不同客户表面要求、材料、工艺参数、支撑可达性和变形风险下，可能有不同的可接受摆法；一个工单也可能有多个互不等价、各有取舍的可行姿态。

因此，**仅把点云送入 PointNet，再让网络回归一个历史方向**，很难完整表达这项决策。它没有显式接收客户的局部要求；以单一历史姿态作唯一目标，会把其他可接受摆法也算成错误；几何编码本身也不会自动给出支撑能否去除、某表面是否受保护或长杆是否会变形等工艺事实。

PointNet 并非不能参与。它可以是候选评分模型中的几何特征提取器，或保留为“根据历史姿态猜参考方向”的基线。更完整的模型需要以工单要求为条件，比较多个候选，并依赖规则检查与支撑评价工具提供有依据的分数。

## 2. 会议材料中的摆放规则

### 2.1 决策优先级

会议纪要与思维导图共同表达了以下顺序：

1. **客户特殊要求与表面保护**：客户指定的装配面、基准面、尺寸精度面、表面质量面及内部流道等，不得违反其朝向和支撑限制。
2. **满足材料和工艺的成型条件**：使用适用的自成形角度、孔径等参数，识别不能只靠局部角度阈值判断的连续圆弧、平面悬垂和离散小特征。
3. **支撑可靠且可处理**：在满足前两项的前提下减少不必要支撑；支撑需考虑位置、体积估计和能否接近、去除，避免放入无法清除的封闭内腔。
4. **降低变形与应力风险**：尽量避免不利截面、突然变化、细长薄壁及大面积朝下导致的风险；必要时为控形使用更多或更强的支撑。
5. **提高生产效率**：在可接受的方案中权衡打印高度、投影面积及打印时长。

会议中的简化排序也写作“客户约束 → 自成形要求 → 支撑量尽量少 → 打印高度低 → 截面均匀”。但变形控制和支撑强度有时会要求增加支撑，故不宜把“所有目标统一加权后取最低分”当作已确认的绝对次序。应由工艺侧确认冲突时的优先级；硬约束须先筛除，软目标再排序。

### 2.2 自成形与悬垂判定

| 结构或条件 | 会议记录的经验 | 对自动化评价的含义 |
|---|---|---|
| 普通悬垂 | 行业默认自成形角约 45°；材料、工艺可人工调整。会议表述为超过阈值可不加额外支撑。 | 角度阈值要成为材料 / 工艺参数，不能硬编码成适用于所有订单的常数。还需统一软件中角度的定义、测量法向方向和“大于 / 小于”的符号约定。 |
| 钛合金水平圆孔 | 会议记录为约 6–8 mm 以下通常无需孔内支撑。 | 以孔径阈值作经验规则；在表格发布前需确认 6 mm 与 8 mm 的适用区间、姿态和工艺条件。 |
| 铝合金水平圆孔 | 会议记录为约 10 mm 以下通常无需孔内支撑。 | 材料是规则条件之一；会议截图的另一处文字写作“10 mm 以上才需支撑”，与纪要一致，但应由统一参数表确认边界和方向。 |
| 均匀渐变圆弧悬垂 | 每层悬垂增量很小，即使局部角度低于阈值也可能自成形。 | 不能只统计“低于 45° 的面面积”；要考虑几何随构建高度的连续变化及逐层悬挑增量。 |
| 突然悬空的平面 | 即使只悬出几毫米，也要求加支撑。 | 单一角度阈值也会漏判。需识别突变平面、悬空长度 / 面积及其与下方实体的支承关系。 |
| 离散微小突出点 | 小而孤立的突出点，即使角度低于阈值，也不必单独增加支撑。 | 需要连通区域、局部面积 / 体积或最小特征尺度等规则；不能让噪声小面触发大量支撑。 |
| 悬空搭桥、悬空凸台 | 思维导图将其列作自成形指标。 | 会议材料未给定跨度、宽度或测试阈值；需整理典型案例并由工艺确认。 |
| 层厚影响 | 层厚越大，台阶效应越明显、悬垂表面质量可能越差，需相应调整阈值与支撑量。 | 阈值需随工艺参数条件化；本条是会议经验，具体映射曲线仍待确认。 |

**口径注意：**“自成形角度 45°”在不同切片器或工程定义中可能从水平面或竖直构建轴测量，比较大小方向也可能相反。实现前应直接核对 FastLayer / Magics 的角度定义和会议所用定义，避免以同一个数字表示相反判定。

### 2.3 客户要求和特殊零件规则

| 零件特点 / 客户要求 | 摆放与支撑要求 | 决策类别 |
|---|---|---|
| 装配面、基准面 | 朝向须符合客户指定要求；会议材料举例为客户指定面必须朝上，不能作为下表面。 | 客户硬约束，须按具体零件标注面及允许方向输入。 |
| 高表面质量 / 高尺寸精度面 | 尽量避免作为下表面或受支撑区域；指定表面不得加支撑。 | 客户硬约束或强偏好，需区分“禁止”与“尽量避免”。 |
| 内部流道、精密小孔 | 即使平放可满足一般自成形标准，也可能需要竖直摆放，以减少下表面挂渣、孔洞堵塞并保持流道质量。 | 特殊件规则；需要将孔轴线 / 流道方向与零件坐标关联，不能只从整体形状推断。 |
| 螺纹、齿面、精密小孔 | 思维导图列为客户要求避免朝下的特殊结构。 | 需要客户提供特征及保护级别；自动几何识别可以辅助，不可擅自替代客户定义。 |
| 过长杆状件 | 即使悬垂角满足自成形标准，也可能因长度过大变形，需加额外控形支撑。 | “过长”目前靠操作经验判断，没有统一量化阈值；长度、截面和工艺条件应进入案例复核。 |
| 大面积朝下的薄壁件 | 容易因残余应力翘曲，优先立放或斜放；若必须大面朝下，需加厚底部支撑轮廓，提高支撑强度。 | 变形 / 支撑强度偏好；需在方案中解释“为什么用较多支撑”。 |
| 内部封闭、支撑无法取出的结构 | 不得添加不可拆除的内支撑；应通过实际打印测试验证可行性。 | 支撑可达性硬约束；如果不加支撑是否可靠仍不确定，应报告风险并请求工艺验证。 |
| 长悬壁、细长薄壁、悬臂 | 思维导图列为截面和应力控制关注项。 | 需要结构特征、逐层截面及必要的仿真 / 工艺指标支持。 |

“不得朝下”和“不得添加支撑”必须分别记录。某面可能不允许朝下，却允许在特定区域支撑；也可能允许朝下但禁止受支撑。将两者混成单个“保护面”标签会导致约束丢失。

### 2.4 支撑和打印效率的优化目标

会议强调在成型可靠、客户要求满足后，尽可能减少支撑面积 / 体积，并考虑支撑易去除，尤其避免在无法到达的型腔内部添加支撑。必要时则需增加支撑强度控制细长件、薄壁件或大面朝下造成的变形。

会议材料描述的支撑体积是**估算值**：把支撑区域网格化，将悬垂面向 Z=0 方向投影后，按块状实体累加。它不是实际镂空支撑结构的精确实体体积。因此：

- 代理值适合候选初筛、同口径方案比较，不可直接称为实际支撑耗材、切片体积或去除工作量。
- 真实支撑布局受支撑生成算法、最小接触点、支撑类型、局部规则等影响，必须记录所用版本和参数。
- 目标不是无条件“支撑越少越好”：安全成型、控形和客户表面保护可能要求增加或重布支撑。

打印效率相关指标包括较小投影面积、较低打印高度和较均匀的逐层截面；思维导图还强调每层截面面积较小、变化平缓，避免突然变化，并减少细长薄壁 / 悬壁造成的应力问题。它们是不同的工艺代价，需说明计算定义，不能不经验证就等同于真实打印时间或残余应力。

## 3. 建议的数据结构：让订单要求成为显式输入

每个待摆放工单建议至少保存下列信息。许多字段当前不在历史 STL / 点云里，需工艺员或客户额外提供。

| 输入组 | 建议字段 | 来源 / 备注 |
|---|---|---|
| 零件几何 | 网格 / 点云、尺度单位、法向、闭合与异常网格检查、孔洞和内部腔体 | CAD / STL 与网格处理；原始单位不可丢。 |
| 材料与工艺 | 合金、层厚、自成形角度规则、孔径经验阈值、支撑参数 / 算法版本 | 以可版本化的工艺表提供；会议值只作初始经验表。 |
| 客户与关键特征 | 装配面、基准面、精度面、表面质量面、内部流道、螺纹 / 齿面；朝向要求、支撑禁区、允许误差级别 | 最好采用 CAD 面 ID / 特征区域及规则属性，不只用自然语言或客户 ID。 |
| 支撑要求 | 支撑类型与参数、接触区域限制、最小接触条件、允许位置、增强 / 加厚要求 | 对接 FastLayer / Magics 当前可用支撑设置。 |
| 支撑可达性 | 封闭腔体、入口尺度、工具 / 人员可达路径、去除方式与风险 | 几何检查只是近似；不可移除结构应人工确认。 |
| 变形 / 应力关注 | 长杆、薄壁、大面朝下、截面突变、支撑控形要求、历史失效案例 | 初期可用结构化标签与人工规则；后续再考虑仿真数据。 |
| 输出偏好 | 多候选数量、可接受的折中、生产优先项、客户特定禁令 | 订单级条件；同一客户不同产品也可能不同。 |
| 结果反馈 | 候选被接受 / 拒绝、原因、实际支撑、后处理、打印结果、人工修改 | 为规则校准、排序学习和审计提供依据。 |

建议信息分为 **客户订单条件**、**材料 / 设备工艺条件** 和 **零件几何 / 特征** 三部分。可先用结构化规则表直接输入各项要求；避免只给网络一个不透明的客户 ID，让模型从少量案例里猜客户习惯。

## 4. Agent / 网络究竟要学会什么

目标应从“形状 → 一个历史方向”扩展为“几何 + 当前订单条件 → 多个通过硬约束的候选 → 支撑与风险评价 → 可解释排序”。

### 4.1 必须遵守的约束

- 不能违反客户明确指定的朝向、禁支撑面及保护面要求。
- 对指定不允许内撑、无法拆除或不可达的区域，不得生成确定性地包含该支撑的推荐。
- 按给定材料 / 层厚 / 工艺配置执行对应自成形阈值与孔径规则，不能将不同材料或订单使用同一默认值。
- 保留设备构建空间、平台和姿态变换限制；超出条件的方向标为不可行。
- 输入缺少关键要求、约束互相矛盾或规则无法判断时，应明确显示“需确认 / 不足以判断”，不能强行输出一个高置信答案。

这些应由**显式规则和约束检查**优先执行，而非只作为神经网络的软惩罚。学习模型给硬禁区高分是不可接受的。

### 4.2 候选评分需要考虑的事项

对每个候选姿态分别计算或预测：

1. 是否符合客户和材料工艺条件；违反了哪条硬约束。
2. 自成形 / 悬垂风险：角度、面积、连续区域、逐层外伸变化、突出的平面与小孤立特征。
3. 支撑代价：估算面积 / 体积、支撑接触位置、是否压在保护面上、是否能到达和去除，以及是否需要控形强化。
4. 变形与应力风险：长杆、薄壁、底部大面、单层截面及其连续变化；在没有仿真或结果数据时只标为风险代理，不报告成品变形概率。
5. 生产效率：打印高度、投影面积和预计时间。会议中尚未给出统一归一化方法及权重。
6. 不确定性和解释：推荐理由、主要代价、与次优方案的差别、是否需要工艺复核。

对客户级偏好，与其强行压成所有订单共用的一个标量“最佳姿态”，早期可以采用硬约束过滤后输出 **Pareto / Top-k 折中候选**：例如一个支撑少、一个变形风险更低、一个高度更低。由工艺员在项目实际条件下确认哪个优先。

### 4.3 模型从哪些数据学习

历史已打印姿态是“曾被采用 / 已验证可用”的样例，但并不自动证明它是唯一最优，也不能把其它所有方向直接标为失败。建议分阶段收集：

- **可用集合标签：** 对每个零件和明确订单条件，记录若干工艺员认可的方向或姿态。
- **硬约束标签：** 某方向违反何种客户禁令、不可移除内撑、工艺限制；以规则结果标注。
- **配对偏好：** 同一零件、同一订单条件下记录 A 优于 B，或两者都可用、都不可用、不确定。
- **实测反馈：** 支撑生成方案、人工改动、拆除难易、打印问题和成品检查结果，保留来源与置信级别。
- **规则参数标定样例：** 材料、层厚下，哪些孔径、跨度、圆弧或平面悬垂通过了真实工艺核验。

只有成对比较时可训练成对排序；多可行方向可用集合式学习 / 排序；只有一个历史方向时，模型应被称为历史姿态模仿器，而不是可打印性判定器。

## 5. 为什么担心单独使用 MLP / PointNet

这项顾虑有充分的建模依据，不过更准确的结论是：**单独的 PointNet 到单一方向映射不足以表达当前决策，不是 PointNet 永远不适合零件摆放。**

1. 典型 PointNet 把点云聚合成全局形状表示，再接一个输出头。如果输入只有点云，模型看不到“这个订单不允许精度面朝下”或“该材料、层厚下孔内应不应该加支撑”。
2. 点云可以表示形状，却不自动给出表面功能语义。客户可能要求一个特定 CAD 面朝向、不得打支撑，需额外标记面区域及规则。
3. 一个三维方向输出通常对应单峰目标；多个都可接受的姿态会互相冲突。普通回归可能折中到任何一个都不合格的方向。
4. PointNet / MLP 不会自带逐层支撑模拟、支撑可清除性或热应力 / 变形评估。只凭历史正例容易把“曾经这样摆”误学成“这样最优”。
5. 本项目现有实验在扩充后 100 件验证集上，PointNet / 轻量等变回归平均方向误差约 64°，进一步表明仅凭当前训练标签和输入做单方向回归尚不够。但这是现有数据与实验条件下的结果，不是证明所有 PointNet 变体无效。

更合适的组合可能是：**PointNet / PointNeXt / PTv3 作为几何编码器 + 结构化工单条件 + 候选姿态特征 + 候选打分头**。即学习

`score = f(零件几何, 候选姿态, 材料与层厚, 客户面要求, 支撑评价结果)`

同时使用确定性规则拦截硬约束，再基于工具指标和工艺反馈排序。多个高分的相互不同候选应被保留，而非把多峰输出求平均。

## 6. Agent 的建议工作流程

### 第一步：检查订单输入

确认单位、材料、层厚、工艺版本和客户要求；若缺少关键基准面 / 禁支撑面 / 流道需求，列出缺项并进入人工确认。

### 第二步：解析并生成候选

从网格及 CAD 语义中识别大面、孔、通道、薄壁、长杆、封闭区域与候选接触面；用几何启发式（面片法向、孔轴、候选方向采样）产生方向，生成落平台后的完整姿态。先处理构建轴；仅当设备布局、流道方向或客户要求需要时，再搜索平台 yaw。

### 第三步：执行硬约束检查

检查客户保护面方向与支撑禁区、材料规则、平台和设备边界、内腔支撑可达性。剔除明确不合格候选并保存失败原因，避免模型用其它低代价抵消硬性违规。

### 第四步：调用支撑与几何评价

对剩余候选尽量调用实际支撑生成 / FastLayer / Magics 工具，获取支撑区域、类型、估算量、碰撞与可去除信息；另外计算打印高度、投影与逐层截面指标。明确区分“实际输出”与“代理估算”。

### 第五步：排序并保留折中解

先按工艺不可行项过滤，再依订单偏好按约束层级或 Pareto 目标排序。输出互相不同的 Top-k 姿态，并展示每个候选的约束通过情况、支撑与风险指标、主要优点和人工复核项。

### 第六步：收集审核与生产反馈

记录工艺员是否采纳、选择理由、改了哪里以及支撑 / 打印后的结果。未知或冲突要标为不确定；不要自动当负例。经确认的反馈再用于规则校准、模型训练和新一轮盲评。

Agent 在这里首先应是**能调用几何、支撑和校验工具的决策编排器**。语言模型可以整理订单要求、解释候选理由、询问缺失信息；不应凭文本常识臆造孔径和材料阈值，也不应取代实际几何计算器。强化学习需要可反复调用、与生产相关的奖励环境；奖励正确性尚未解决前，直接训练策略只会更快优化错误目标。

## 7. 当前可形成的初步评估表

每个候选至少输出这些可核查字段：

| 结果字段 | 形式 | 阶段 |
|---|---|---|
| 客户硬约束通过 / 违反项 | 布尔值 + 面区域 / 规则 ID | 推荐前必须 |
| 材料、层厚及自成形阈值来源 | 条件 + 表格版本 | 推荐前必须 |
| 关键孔、流道和封闭内腔风险 | 特征、方向、人工核验状态 | 先报风险，再验证规则 |
| 悬垂 / 自成形评价 | 区域、角度、逐层增长、平面 / 圆弧类型 | 可解释的几何诊断 |
| 支撑区域、体积代理或实际生成量 | 单位、算法版本、参数、是否实际值 | 强制标明估算性质 |
| 支撑可移除性 / 工具可达性 | 规则检查 + 人工状态 | 封闭腔体重点复核 |
| 变形 / 应力关注项 | 长杆、薄壁、大面朝下、截面变化等风险标记 | 当前以代理特征为主 |
| 打印高度、投影面积、逐层截面 | 数值及定义 | 效率与应力辅助指标 |
| 工艺员接受 / 拒绝 / 偏好原因 | 标签 + 备注 + 操作者 / 日期 | 用于模型反馈 |

每次推荐应记录工单输入快照、候选姿态矩阵、模型 / 规则版本和指标来源，以便复现同一推荐。

## 8. 未决问题及下一步

会议明确会整理典型案例并进行进一步专项讲解。在具体实现前建议确认：

1. 45° 从哪条参考方向测量，FastLayer / Magics 如何定义角度、阈值边界怎么判。
2. 钛合金 6–8 mm 和铝合金 10 mm 的适用条件、区间边界、孔轴方向，以及层厚 / 支撑策略是否改变阈值。
3. 突然平面悬垂、渐变圆弧、孤立点、搭桥 / 凸台的典型例子与可计算界限。
4. 客户保护面如何从 CAD / 图纸传入；“不得朝下”和“不得支撑”分别如何标记。
5. 流道应“竖直”的具体定义、允许偏角，以及何种挂渣 / 堵塞结果判定不可接受。
6. 长杆“过长”的量化与材料、直径、截面、摆向的关系；薄壁和大面朝下的支撑轮廓如何加厚。
7. 可移除性如何核验；内部封闭结构需要判为硬禁区、风险提示还是必须试打印。
8. 投影面积、打印高度、逐层截面均匀性、支撑体积及变形风险的测量定义与冲突优先级。
9. 能否取得 FastLayer / Magics 的支撑计算结果、配置文件、历史支撑后处理记录及典型打印成功 / 问题案例。

推荐按代表零件建立小型规则验证集：每件保留网格、订单 / 工艺条件、至少两三种候选摆法、工具生成支撑预览、工艺员最终评价和原因。先验证“硬约束拦截 + 可解释指标 + Top-k 展示”的闭环，再决定是否训练条件化排序网络，最后再评估 Agent 或强化学习。

## 9. 与此前实验结论的关系

当前候选打分实验输入点云和候选方向，预测分数，确实比输出唯一方向更容易容纳多个候选。可信基线在同组 100 个留出零件上，Top-1 与历史方向相差不超过 20° 的比例是 28%，Top-5 至少一个候选命中为 52%。这些数字仅说明与**历史参考方向的角度覆盖**，不表示候选满足这份会议规则，也不表示实际打印可用。

目前实验未将客户保护面、流道方向、孔径规则、支撑可移除性、Layer-by-layer 自成形与变形目标完整纳入输入和验证。因此会议经验补足了任务建模的关键部分：后续评价目标应从“角度是否像历史 GT”扩展到“给定这个订单的条件后，候选是否满足工艺硬约束、生成的支撑是否合理并能达到客户质量要求”。
