# 简化支撑生成器 v0

## 目标和边界

这是一个固定姿态的几何支撑评估 / 预览原型，不是 Magics SG+ 或 e-Stage 的复刻，也不作为生产支撑文件直接下发。它把“悬垂面筛选 → 已标注特征豁免 → 向下射线找接触位置 → 输出竖直支撑柱代理”做成可重复运行的工具，并为之后的姿态搜索提供硬约束和支撑量近似。

当前程序**不自动识别**横孔、搭桥、凸台、CAD 面语义或客户禁支撑区域。它通过网格三角面索引接收这些标注，并按配置表的尺寸阈值执行豁免。这样可以先验证角度、射线和禁区逻辑；自动特征识别需另行标定。

## 判定约定

- 构建方向默认是输入坐标系的 `+Z`；平台默认是 `Z=0`，零件坐标保留不平移。`--build-up x y z` 可旋转构建方向，`--platform-offset-mm` 可指定沿构建方向的平台平面坐标。
- 自成形角按“向下的表面与水平面的夹角”处理：水平向下为 0°，竖直面为 90°。向下法向单位向量为 `n` 时，角度为 `acos(-n·up)`；角度 `<=` 材料阈值时成为悬垂候选，等于阈值按保守规则保留。
- 横孔直径、搭桥跨度、凸台尺寸必须**严格小于**对应阈值才免支撑；恰好等于阈值仍保留为候选。
- 禁支撑面自身落入候选区，或向下支撑落点碰到禁支撑面，都会记为硬违规；违规区域不生成支撑柱，也不把该姿态报告为可行。
- 程序把坐标和尺寸按 mm 解释。输入网格必须已放在预期的打印坐标系中，平台高度默认为 0；程序不会自动把零件最低点移到平台。现有 PJF 导出记录保留了原始坐标，仓库审计仍把其单位标为未确认，因此下方历史样例中的毫米数值只能视为按 mm 解释的演示值，需用已知尺寸再确认。

规则值来自任务中提供的材料表，版本化保存在 [`support_rules_v0.json`](../../configs/support_rules_v0.json)。目前它们仍是待核对的初始工艺值，尚未由 Magics 参数配置、打印试样或工艺部门签字标定。

## 运行

```bash
python tools/generate_simplified_supports.py part.stl \
  --material AlSi10Mg --mode standard \
  --annotations configs/support_annotations.example.json \
  --preview outputs/part_support_preview.png \
  --support-obj outputs/part_support_columns.obj \
  --output outputs/part_support_report.json
```

支持 OBJ、ASCII / binary STL，以及含 `vertices` 和 `faces` 数组的 NPZ。标注索引是输入网格的 0-based 三角面索引。标注文件结构如下：

```json
{
  "no_support_face_indices": [12, 13],
  "features": [
    {"kind": "horizontal_hole", "face_indices": [20, 21], "diameter_mm": 5.5},
    {"kind": "bridge", "face_indices": [31], "span_mm": 1.5},
    {"kind": "boss", "face_indices": [42], "size_mm": 0.8}
  ]
}
```

每个带特征的面片组须由使用者确认属于相应特征。示例配置里的空三角面索引不会豁免任何网格面。

## 支撑代理

每个候选面按 `--sample-spacing-mm` 生成接触采样点。沿构建轴反方向找第一个位于平台以上的网格交点；找不到时落到平台。输出是由采样点、接触面和高度定义的竖直柱，OBJ 里的圆柱半径默认为 0.4 mm。报告中的柱体积是“柱半径 × 柱高度”的几何代理，不包括网格支撑、接触齿、支撑壁、树枝合并或其他真实支撑结构。

## 当前样例

`part_10001_vs_magics_preview.png` 对比一件初始 PJF 记录中的输入零件、随项目保存的支撑网格和简化算法输出。对应 STL 为零件 ID 10001、子支撑 ID 10004，二者保留原始网格坐标，项目变换为单位矩阵。样例使用 AlSi10Mg 的 `standard` 阈值（45°）、1.5 mm 采样间距、0.4 mm 柱半径。

本次运行得到：

| 项目 | 结果 |
|---|---:|
| 零件三角面数 | 2,694 |
| 角度筛出的悬垂面 | 216 面，面积代理 4,735.4 mm² |
| 简化支撑柱 | 2,104 根 |
| 平台落点 / 零件面落点 | 2,061 / 43 |
| 平均 / 最大柱高 | 19.90 / 54.72 mm |
| 竖直柱体积代理 | 21,045.9 mm³ |
| 硬约束违规 | 0 |
| 项目中保存的 Magics 支撑网格 | 35,995 面 |

图上可以看到当前算法生成离散直柱，而项目保存的是连续区域支撑。这个结果仅证明读取、候选筛选、射线求交、报告和可视化链路可以工作；由于尚未核对该项目的 Magics 支撑配置、人工修改状态及构建模式，不能把差异直接归结为算法优劣，也不能据此声称两者数值一致。

## 验证

运行：

```bash
python -m unittest tests.test_simplified_supports -v
```

测试覆盖材料/模式参数、角度定义与阈值边界、特征豁免严格边界、支撑射线落点，以及禁支撑源面和落点违规。

## 后续需要校准的点

1. 让工艺人员确认 316L、AlSi10Mg、TC4 的普通模式与 AM BUILD 阈值，以及单位和角度定义。
2. 给代表性零件的横孔、搭桥、凸台和禁区提供面片标注，比较预览与 Magics 同配置输出。
3. 先补连通区域统计、孔轴 / 直径识别和支撑区域合并；再评估柱径、接触点和实际支撑类型。
4. 对射线落到零件面的情况增加稳定性 / 支撑依赖检查，并检查支撑柱与实体碰撞及内腔可拆除性。
5. 只有固定姿态支撑区域和落点经过复核后，再在外层接入方向采样和候选排序。
