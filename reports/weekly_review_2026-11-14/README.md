## 关键口径

- 工业件的方向指标指构建轴，不计自由 yaw。当前仍不等于完整工艺姿态和可打印率。
- 932 为扩充数据的训练件数，100 为验证件数，总计 1,032 个代表件。
- PointNet 公开金字塔 0.71° 为独立测试平均值；打分 0.463° 为 100 个验证样本上的结果，包含局部搜索，不作严格模型优劣比较。
- 真实件回归结果为验证平均误差。193 件试验的完整视图数与预算不同，单独呈现 160 视图配对比较。
- 打分可信基线使用 `runs/build_direction_scorer_centred_2026-11-10/evaluation.json`。报告首页和第 8 页重点改为同一组 100 个验证零件的 ≤20° 覆盖率：Top-1 为 28%（28 件），Top-5 为 52%（52 件）。Top-1 取最高分候选单起点局部细化后的结果，Top-5 取网格候选前五的最近夹角；两者不使用相同的细化流程。近距离负样本和点密度对照也统一展示相应指标，分别为 27% / 56% 和 25% / 52%。
- 原始误差仍保留在证据中：首选平均 73.1304°、中位 48.2195°，历史排名中位分位 0.013671875。训练期 `best_metrics.json` 与最终细化评估不可混用。
- 近距离负样本、搜索重启及集成数字因评估设置不同，按代表结论展示，不宣称严格单变量消融。
- 多峰 / 多解是需要检验的建模假设，未把真实件误差全部归因于标签。
- 打分排序表现改善，不代表已经优于所有回归方法，也不代表推荐已通过工艺验收。
- 增量旋转、RL 和 LLM Agent 均为后续方向，不计入已完成实验。
