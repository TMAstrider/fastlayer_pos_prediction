# 打分器实验 1：无增强基线（2026-11-10）

状态：已废弃，仅作为失败记录保留。**结论：存在坐标系泄漏，指标不可信。**

## 目的

把“单方向回归”换成分数场 \(s(\text{shape},u)\)：物理项做先验，点云编码器学残差；
人工方向为正样本，规则低代价区的方向为硬负样本。第一版用来验证训练管线是否通。

## 配置

| 项 | 值 |
|---|---|
| 候选 | 512 Fibonacci 方向 |
| 正样本 | 人工方向（存储坐标系 +Z） |
| 负样本 | 4 个硬负（物理代价前 10%、离人工 >20°）+ 4 个随机 |
| 损失 | 9 路 listwise softmax，温度 0.05 |
| 输入 | 2048 点 XYZ＋法向，按候选方向旋转 |
| 物理特征 | 悬垂、支撑、高度、接触，逐形状标准化 |
| 模型 | 点 MLP 64-128-256 + max/mean 池化 + 3 层头，116,289 参数 |
| 优化 | AdamW，lr 1e-3，60 轮，batch 48 形状 |

## 诊断：两个泄漏

1. **人工排名恒为 0，而 top-1 在 14°–117° 之间乱跳** —— 两者不可能同时成立（若人工排第一，
   top-1 应该落在人工附近）。唯一解释：分数在“原始存储坐标系”上有一个尖峰。
2. 训练时正样本永远在存储坐标系，负样本是任意旋转；而**旋转后没有去中心**，零件仍在离原点
   很远的位置（存储时底在 z≈4 mm）。模型因此学的是“这个点云是不是在原地”，不是“这个方向好不好”。
3. yaw 没有随机化，进一步让“yaw=存储 yaw”成为可识别信号。

证据：60 轮训练 loss 降到 0.0008，但验证 top-1 无趋势；人工排名在每一轮都恰好是 0。

## 结论

- 该版本的任何数字都不能用；包括“top-1 13.9°”这种看起来很好的数字。
- 教训：打分器的输入必须在旋转前**去中心 + 尺度归一**，并对正负样本都做随机 yaw；
  否则模型会学坐标系而不是几何。
